## Protocols and platforms

- [NUT-07](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/07.md),
  [NUT-08](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/08.md),
  [NUT-09](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/09.md),
  [NUT-13](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/13.md):
  Spend state, change, prepared outputs and counter recovery.
- [NUT-19](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/19.md),
  [NUT-20](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/20.md),
  [NUT-27](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/27.md):
  Request cache, quote binding and separately defined mint-list backups.
- [BOLT11](https://github.com/lightning/bolts/blob/master/11-payment-encoding.md):
  authoritative invoice specification; a complete independent test-vector run
  remains open, therefore no full conformance claim.
- [NIPs at the checked revision](https://github.com/nostr-protocol/nips/tree/a2494f4f81d46684e5814a9bf35e2b1df978f955):
  `06.md`, `07.md`, `44.md`, `46.md`, `55.md`, `60.md`, `61.md`, `78.md`, `5A.md`.
  NIP-06 is draft/unrecommended; 60/61/78 are drafts, not complete
  Bearlett recovery/coordination protocols. Current NIP-44 has an extended
  length format; actual signer/relay support remains to be tested.
- [Capacitor Android](https://capacitorjs.com/docs/android),
  [Environment](https://capacitorjs.com/docs/getting-started/environment-setup),
  [Version 8](https://capacitorjs.com/docs/updating/8-0): Node 22+, Android Studio
  2025.2.1+, SDK 36, minimum API 24; AGP 8.13.0, Gradle 8.14.3, Kotlin 2.2.20.
  Android Studio supplies the required JDK; a separate Java installation is
  not an end in itself. Pin exact chosen patch versions in the Android spike.
- [Android Keystore](https://developer.android.com/privacy-and-security/keystore)
  and [Capacitor Preferences](https://capacitorjs.com/docs/apis/preferences):
  hardware-dependent key protection versus simple preferences; not a finished
  encrypted transactional wallet vault.
- [Web NFC](https://developer.chrome.com/docs/capabilities/nfc): HTTPS,
  top-level context, user action, visibility and NDEF limits.
  [Android NFC](https://developer.android.com/develop/connectivity/nfc/nfc)
  additionally needs a real hardware test.
- [Android emulator networking](https://developer.android.com/studio/run/emulator-networking):
  `10.0.2.2` as host alias, not `127.0.0.1` of the Android guest.
- [Amber](https://github.com/greenart7c3/Amber): a concrete external Android signer
  for a later NIP-55 device test; not installed/tested in this session.

## License boundaries

Cashu Sync contains an MIT License for the wallet part (`wallet/LICENSE.md`),
but no proven general license for the relay part. Granola contains
neither LICENSE nor a package license declaration at the checked revision.
Envelope declares MIT in the package, without a found LICENSE text. Workshop
contains an MIT License. Findings and protocol ideas are usable; code uptake
requires a matching explicit license plus origin notices.

No code from these projects was taken into the wallet core and
nobody was contacted. Toolchain and transitive dependencies have their own
license terms; Bearlett's MIT License does not change those.
