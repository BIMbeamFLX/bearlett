## Protokolle und Plattformen

- [NUT-07](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/07.md),
  [NUT-08](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/08.md),
  [NUT-09](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/09.md),
  [NUT-13](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/13.md):
  Spendzustand, Wechselgeld, vorbereitete Outputs und Counter-Recovery.
- [NUT-19](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/19.md),
  [NUT-20](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/20.md),
  [NUT-27](https://github.com/cashubtc/nuts/blob/38d243a1141e69fbcb94a35123d1708d01507044/27.md):
  Requestcache, Quote-Bindung und separat definierte Mintlisten-Backups.
- [BOLT11](https://github.com/lightning/bolts/blob/master/11-payment-encoding.md):
  maßgebliche Invoice-Spezifikation; vollständiger unabhängiger Testvektorlauf
  bleibt offen, daher keine vollständige Konformitätsbehauptung.
- [NIPs am geprüften Stand](https://github.com/nostr-protocol/nips/tree/a2494f4f81d46684e5814a9bf35e2b1df978f955):
  `06.md`, `07.md`, `44.md`, `46.md`, `55.md`, `60.md`, `61.md`, `78.md`, `5A.md`.
  NIP-06 ist draft/unrecommended; 60/61/78 sind Entwürfe, keine vollständigen
  Bearlett-Recovery-/Koordinationsprotokolle. Aktuelle NIP-44 hat erweitertes
  Längenformat; tatsächliche Signer-/Relay-Unterstützung bleibt zu testen.
- [Capacitor Android](https://capacitorjs.com/docs/android),
  [Umgebung](https://capacitorjs.com/docs/getting-started/environment-setup),
  [Version 8](https://capacitorjs.com/docs/updating/8-0): Node 22+, Android Studio
  2025.2.1+, SDK 36, Minimum API 24; AGP 8.13.0, Gradle 8.14.3, Kotlin 2.2.20.
  Android Studio liefert das benötigte JDK; eine separate Java-Installation ist
  kein Selbstzweck. Exakte gewählte Patchversionen im Android-Spike pinnen.
- [Android Keystore](https://developer.android.com/privacy-and-security/keystore)
  und [Capacitor Preferences](https://capacitorjs.com/docs/apis/preferences):
  hardwareabhängiger Schlüsselschutz versus einfache Preferences; kein fertiger
  verschlüsselter transaktionaler Wallet-Vault.
- [Web NFC](https://developer.chrome.com/docs/capabilities/nfc): HTTPS,
  Top-Level-Kontext, Benutzeraktion, Sichtbarkeit und NDEF-Grenzen.
  [Android NFC](https://developer.android.com/develop/connectivity/nfc/nfc)
  braucht zusätzlich echten Hardwaretest.
- [Android Emulator-Netzwerk](https://developer.android.com/studio/run/emulator-networking):
  `10.0.2.2` als Host-Alias, nicht `127.0.0.1` des Android-Gasts.
- [Amber](https://github.com/greenart7c3/Amber): konkreter externer Android-Signer
  für einen späteren NIP-55-Gerätetest; in dieser Session nicht installiert/getestet.

## Lizenzgrenzen

Cashu Sync enthält eine MIT-Lizenz für den Wallet-Teil (`wallet/LICENSE.md`),
aber keine nachgewiesene allgemeine Lizenz für den Relay-Teil. Granola enthält
im geprüften Stand weder LICENSE noch eine Paket-Lizenzdeklaration. Envelope
deklariert MIT im Paket, ohne gefundenen LICENSE-Text. Workshop enthält eine
MIT-Lizenz. Erkenntnisse und Protokollideen sind verwertbar; Codeübernahmen
setzen eine passende ausdrückliche Lizenz samt Herkunftshinweisen voraus.

Es wurde kein Code aus diesen Projekten in den Wallet-Kern übernommen und
niemand kontaktiert. Toolchain- und transitive Abhängigkeiten haben eigene
Lizenzbedingungen; Bearletts MIT-Lizenz ändert diese nicht.
