# Project directory suggestions

Prepared descriptions for maintainers to consider after review/release. No
outreach or listing submission is performed automatically.

## LNURLcash wallet directory

**Bearlett Wallet** — an MIT-licensed napplet for LNURLcash and Cashu bearer sats.
Includes encrypted backup/recovery and transfers between the two protocols over
Lightning. **Bearlett Notes** is a separate designer with image upload and
appearance-only handoff to Wallet. Based on dni's LNURLwallet.

Project: https://github.com/BIMbeamFLX/bearlett

## Cashu wallet directory

**Bearlett** — a napplet wallet for unbound Cashu sats (cashuA/B, BOLT11) and
LNURLcash. Cashu operations require the experimental Kehto capability; encrypted
journals retain proofs, deterministic counters, quotes and fee change. A separate
Notes napplet designs bearer artwork. Development preview pending review.

Suggested topics: `cashu`, `lnurlcash`, `lightning-network`, `bitcoin`, `wallet`,
`napplet`, `bearer-assets`, `typescript`, `solidjs`.
